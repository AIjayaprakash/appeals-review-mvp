# Clinical Policy Bulletin CP-OPHTH-005
## Eyelid Surgery (Blepharoplasty) — Coverage Exclusion & Exception Criteria

**Effective date:** 2025-01-01 · **Applies to:** CPT 15822, 15823

### Coverage exclusion

Blepharoplasty (upper or lower eyelid surgery) is excluded from coverage as a cosmetic procedure **unless** the exception below is met.

### Exception criteria

Blepharoplasty is covered as reconstructive, not cosmetic, only when a formal visual field test (e.g., Humphrey visual field test, taped vs. untaped) demonstrates **at least 30% obstruction of the superior visual field** attributable to dermatochalasis or ptosis. The test result must be included with the request.

### Common reasons for denial

- No visual field test of any kind included in the submission.
- Visual field test shows obstruction below the 30% threshold.
- Photographic documentation submitted in place of a formal visual field test.

### Appeal guidance

An appeal should include the visual field test result directly. A clinical narrative describing visual difficulty without an accompanying test result does not meet the exception criteria, however reasonable the description sounds.
